Couleur OpenAI — pourquoi le teal #10A37F ? Le nœud officiel est monochrome : un noir pur disparait sur la barre sombre, un blanc pur disparait sur la barre claire. Comme notre icone est couleur (non-template) et ne s'inverse pas, on retient le teal de marque OpenAI, une teinte medium qui garde son contraste sur les deux apparences — exactement comme l'orange #D97757 du symbole Claude. Lisibilite a 16 px : le sunburst Claude et le nœud OpenAI restent reconnaissables ; l'entrelacs du nœud se lit nettement en @2x (retina) et se ramollit legerement en @1x non-retina — si un fond exotique posait probleme, ajouter un halo neutre 0.5 px (ombre douce) autour du mark, non requis par defaut.
6 · Spec d'implementation pour Gimli

Generer l'icone RGBA au runtime (Tauri)

  • Source de verite : les SVG ci-dessus + la table de cotes (§2). Deux voies possibles.
  • Voie A (SVG → raster) : composer un SVG 40×18 (logo + rects), le rasteriser en RGBA @2x (80×36) avec resvg/usvg (crate Rust, deja pur), puis app.tray_icon().set_icon(Image::from_rgba(...)).
  • Voie B (dessin direct) : dessiner les rects avec tiny-skia depuis la table de cotes (le logo reste un PNG/quad statique pre-rasterise, seule la couche barres est recalculee).
  • Mapping : w = max(2, (pct/100·18)).round() ; teinte selon seuils 50/20 ; estimate → remplir avec un motif hachure 45° ; none → dessiner la piste pointillee, pas de fill.
  • Repli 1 barre : si un seul quota, dessiner une barre unique a y=6.5 (h=5) ; sinon deux barres a y=3 et y=10.
  • Clair/sombre : icone non-template (couleur de marque). Ne pas activer le mode template. La piste #8E8E93 + les fills vifs passent sur les deux appearances ; pas besoin de deux jeux d'assets. Si un fond exotique posait probleme, ajouter une ombre portee douce de 0.5 px (halo neutre) — non requis par defaut.
  • Retina : fournir 40×18 et 80×36 ; laisser macOS choisir selon l'ecran.
  • Refresh : recalculer et re-set_icon a chaque maj de quota (le logo ne bouge pas — cache-le).
Perf : seule la largeur des deux rects change entre deux rafraichissements. Garder le logo rasterise en cache et ne recomposer que la bande de droite suffit — cout negligeable.
